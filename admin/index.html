ورود به پنل مدیریت

برای ذخیره‌ی تغییرات روی GitHub به یک توکن نیاز است. توکن فقط در همین مرورگر ذخیره می‌شود.

  1. در GitHub به Settings → Developer settings → Personal access tokens → Fine-grained tokens برو و Generate new token بزن.
  2. در Repository access فقط ریپوی jahangir-ceram-catalog را انتخاب کن.
  3. در Permissions ← Repository permissions مقدار Contents را روی Read and write بگذار.
  4. توکن ساخته‌شده را اینجا بچسبان.
